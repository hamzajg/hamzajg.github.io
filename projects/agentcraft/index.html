THE PRODUCT

Local agents.
Human direction.

AgentCraft runs a configurable team of specialized agents against a project workspace. Its documented loop moves from specifications and architecture to planned iterations, implementation, review, and user approval. The repository emphasizes local Ollama models, resumable checkpoints, and reusable skills and frameworks.

01 — PRIVATE BY DEFAULTLocal model workflow

Ollama and Aider power a setup that does not require cloud API keys.

02 — SHORT FEEDBACK LOOPSReview each task

Agents implement, get immediate review, and rework before the iteration moves on.

03 — EXTENSIBLE TEAMSkills & frameworks

Configure agent personas and reusable skills, or add a new self-contained agent.

WALKTHROUGH

Make the work
inspectable.

The flow starts with human-authored context and stays resumable and reviewable throughout. Pick a step to see the documented workflow.

Start with project context

Write requirements and architecture docs, then configure the workspace, model, output path, and optional methodology in workspace.yaml.

Let the team work in iterations

Spec, architect, planner, and developer agents collaborate through small tasks. AgentCraft resumes from checkpoints and can run selected phases or parallel tasks.

Inspect before approving

Immediate task review and user approval gates keep generated changes in a human-directed workflow. A local communications UI offers chat, monitoring, and RAG inspection.
