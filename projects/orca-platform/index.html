THE PRODUCT

One API.
Many local models.

ORCA sits between OpenAI SDK-compatible clients and Ollama workers across a local network. The documented gateway combines key-based authentication, round-robin routing, health monitoring, streaming proxy support, a model index, and request logging. This dashboard is an illustrative view; its sample node states and chart do not come from a live service.

01 — CONNECTFamiliar API surface
